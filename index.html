이 시스템의 AI 위임 수준
가트너 인간-AI 위임 프레임워크 7단계 중, 본 체계는 2단계(자문)~3단계(권장)에 위치합니다. AI는 분석하고 제안하지만, 승인·실행 여부는 담당자가 최종 확인합니다.
완전 자동화(7단계 자율)를 목표로 하지 않습니다. AI가 자료를 수집·분석·정리하고, 최종 결정은 사람이 내리는 구조를 원칙으로 설계했습니다.

설계 근거. AI 위임 수준 구분은 가트너 «의사결정 증강을 위한 인간-AI 위임 프레임워크»(2024)의 7단계 모델을 참고해 구성했습니다.

독립 실행 안내. 이 파일은 다운로드해서 로컬 브라우저에서 단독으로 사용하도록 만들어졌습니다. 상단에 본인의 Google Gemini API 키(aistudio.google.com에서 발급)를 입력해야 각 단계 버튼이 동작합니다. 키는 브라우저 밖으로 전송되지 않고 이 페이지 안에서만 사용되며, "이 브라우저에 저장"을 체크하면 로컬 저장소(localStorage)에 남아 다음에 다시 입력하지 않아도 됩니다.
